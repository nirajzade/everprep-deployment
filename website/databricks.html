All platform features

Storage and table formats

  • Delta Lake: ACID transactions, time travel, MERGE, schema enforcement and evolution, constraints, and identity and generated columns`
  • Delta optimizations: Change Data Feed, deletion vectors, liquid clustering, Z-ORDER, OPTIMIZE and VACUUM, predictive optimization, type widening, row tracking, and VARIANT type`
  • Shallow and deep clone`
  • UniForm: lets other engines read Delta tables as Iceberg`
  • Managed and foreign Apache Iceberg tables: Unity Catalog managed Iceberg tables, foreign Iceberg tables, and Iceberg v3 features are generally available. With v3, the physical Parquet data files on disk are now shared between Delta and Iceberg tables. databricksflexera`
  • Catalog commits and multi-table transactions: catalog commits expand managed table interoperability and unlock multi-statement, multi-table transactions databricks`
  • Volumes: governed storage for non-tabular files`
  • Workspace files`
  • DBFS (legacy)`

Ingestion (Lakeflow Connect)

  • Managed connectors: relational databases like SQL Server and PostgreSQL, or SaaS platforms like Salesforce, plus Workday, ServiceNow, Google Analytics, SharePoint, NetSuite and more jrvs`
  • Over 100 connectors: including community-developed connectors and options for customers to build their own flexera`
  • Query-based connectors: for example, an Oracle connector that provides incremental loads via a cursor column (and supports SCD1/SCD2 and soft/hard deletes), but it’s not log-based CDC databricks`
  • Zerobus Ingest: a push-based API that handles high-rate, small-row event data and lands it directly into open Delta tables, with Kafka-compatible APIs flexera`
  • Auto Loader: incremental file ingestion from S3, ADLS and GCS`
  • COPY INTO, read_files, and file upload UI`
  • File events: enabled by default on new external locations databricks`
  • Streaming sources: Kafka, Kinesis, Event Hubs and Pub/Sub`
  • Lakeflow Connect Free Tier`

Transformation (Lakeflow Spark Declarative Pipelines, formerly DLT)

  • Streaming tables and materialized views, including incremental refresh`
  • Expectations: built-in data quality rules`
  • AUTO CDC: replaces Apply_Changes for SCD1 or SCD2 operations jrvs`
  • AUTO CDC FROM SNAPSHOT: CDC when the source only provides snapshots`
  • Flows, append flows and sinks`
  • Real-Time Mode: achieves as low as 5 ms latency for time-critical workloads flexera`
  • Open-source Spark Declarative Pipelines: DLT becomes an open Apache Spark standard github`
  • Lakeflow Designer: no-code, natural-language pipeline builder that generates real Spark Declarative Pipelines code`
  • Visual data prep`
  • Structured Streaming: stateful processing (transformWithState) and watermarks`

Orchestration (Lakeflow Jobs)

  • Task types: notebooks, SQL, pipelines, dbt, Python wheels, JARs, run-job and more`
  • Triggers: schedule, file arrival, table update and continuous`
  • Control flow: conditional (if/else) tasks, for-each loops, job parameters, repair and rerun`
  • Serverless jobs`
  • Integrations: more than 50 integrations for orchestrating external systems flexera`
  • Unified run tracking: filter all your pipeline runs by status, time, run-as user, run ID, and error codes in real time databricks`

Compute

  • Cluster types: all-purpose, job and pools; cluster policies, autoscaling, spot instances and init scripts`
  • Serverless compute for notebooks, jobs, pipelines and SQL`
  • Databricks Runtime and ML Runtime, including LTS versions`
  • Photon: vectorized query engine`
  • SQL warehouses: Classic, Pro and Serverless`
  • Lakehouse//RT: a new SQL warehouse type in Databricks, starting with read-only analytical workloads, powered by the new Reyden engine (Beta) flexera`
  • AI Runtime: serverless GPU compute for deep learning and LLM training with multi-node support flexera`
  • Databricks Sandbox: isolated virtual machines with downscoped Unity Catalog access for running agent code addepto`

Governance (Unity Catalog)

  • Organization: three-level namespace (catalog.schema.table), metastores, managed and external tables, storage credentials and external locations`
  • Access control: grants, row filters and column masks, and attribute-based access control (tag-driven policies)`
  • Observability: column-level lineage, audit logs, system tables (billing, lineage, query and Lakeflow), tags and data classification`
  • Data quality monitoring (formerly Lakehouse Monitoring), including anomaly detection`
  • Open access: Iceberg REST catalog, credential vending and open-source Unity Catalog`
  • Business semantics: Metric Views and Metrics, Domains, and Business Glossary. Per the summit coverage, Domains (Public Preview) organize data and AI assets into business-aligned categories. flexera`
  • Unity AI Gateway: spend caps, smart routing, contextual security policies, MCP server registry, agent tracing via MLflow flexera`

Federation and sharing

  • Lakehouse Federation: allows you to query external data sources without moving your data databricks`

    • Query federation to PostgreSQL, MySQL, SQL Server, Oracle, Snowflake, Redshift, BigQuery, Synapse, Teradata and others. It pushes queries down via JDBC to the foreign database. databricks`

    • Catalog federation for Hive metastore, AWS Glue and Snowflake`

  • Delta Sharing: Databricks-to-Databricks and open sharing`

  • OpenSharing: Superset of Delta Sharing extending the protocol to AI assets including agents, models and skills; on-premises storage support included flexera`
  • Databricks Marketplace: data, models, notebooks and apps`
  • Clean Rooms: privacy-safe collaboration on shared data`

Data warehousing and BI (Databricks SQL)

  • Querying: SQL editor (with dynamic parameters), saved queries, alerts, query history and query profile`
  • SQL language features: SQL scripting, stored procedures, temp tables and collations`
  • AI/BI: AI/BI Dashboards and Genie spaces (natural language to SQL)`
  • AI Functions: ai_query, ai_extract, ai_classify, ai_parse_document, ai_forecast and more. aiextract is now generally available, and aiclassify is now generally available. databricks`
  • Office and BI integrations: Excel Add-in, Google Sheets connector, and Power BI and Tableau integrations`
  • Lakebridge: AI-powered, free data warehouse migration tool flexera`

Operational database (Lakebase)

  • Managed Postgres: Lakebase combines familiar Postgres with the scalability and economics of open lakehouse storage. It now supports Postgres 18. databricks`
  • Autoscaling and scale-to-zero: new Lakebase Autoscaling instances now scale to zero by default after 24 hours of inactivity databricks`
  • Branching, snapshots and instant rollback`
  • Disaster recovery: high availability and cross-cloud, cross-region disaster recovery`
  • Sync between Lakebase and the lakehouse: synced tables (reverse ETL from Delta), and Lakehouse Sync and Change Data Feed (Public Preview)`
  • Lakebase Search: hybrid vector and full-text retrieval (Beta)`
  • OpenTelemetry export: export Lakebase Postgres metrics and logs to any OTLP-compatible observability backend databricks`
  • LTAP: pairs Lakebase (transactions) with the lakehouse (analytics) on one copy of open-format data. Announced, coming soon. addepto`

AI and ML (Agent Bricks, formerly Mosaic AI)

  • Agent Bricks: expanded beyond declarative agents to serve as the umbrella for all Databricks AI capabilities databricks`

  • Prebuilt agents:`

    • Knowledge Assistant: a document Q&A agent with citations`

    • Supervisor Agent: multi-agent orchestration that can use UC functions, tables, vector indexes, MCP servers, web search and other agents as tools`

    • Information Extraction and Document Intelligence`

  • Agent infrastructure:`

    • Agent Framework`

    • Agent Memory Service: managed agent memory built on Lakebase, with short-term (session) and long-term (cross-session) tiers addepto`

    • Managed and external MCP servers`

  • Model Serving: custom models, Foundation Model APIs (pay-per-token and provisioned throughput), external models, and models from OpenAI, Anthropic, Gemini, Qwen, Kimi and Grok`

  • Vector Search`
  • Features: feature engineering in Unity Catalog, online feature serving and online tables`
  • Managed MLflow 3: experiment tracking, model registry in Unity Catalog, tracing, evaluation and judges, and prompt registry`
  • Other ML tools: AutoML, AI Playground and fine-tuning`
  • Omnigent: Open source meta-harness that sits above existing agent frameworks, enabling agent composition, collaboration and centralized governance flexera`

AI assistants (the Genie family)

  • Databricks Assistant: includes Agent Mode, and users can now create skills to extend Databricks Assistant in agent mode azure`
  • Genie Code: AI coding agent built for data engineering and ML workflows, plus an ML-specific variant flexera`
  • Genie ZeroOps: Autonomous background agent that monitors pipelines, detects failures, investigates root causes and proposes fixes flexera`

  • Genie One: an AI coworker for business users. Related pieces:`

    • Genie Agents: reusable agents saved from Genie One conversations`

    • Genie Ontology: the context layer behind Genie One`

  • Databricks One: a simplified interface for business users`

  • Genie in Microsoft Teams, M365 Copilot and Slack`

Apps and developer tools

  • Databricks Apps, App Spaces, Serverless Micro Apps and Genie App Builder (Private Preview)`
  • Notebooks: multi-language (Python, SQL, Scala, R) and real-time collaborative`
  • Git folders (formerly Repos)`
  • Databricks Asset Bundles: infrastructure-as-code style CI/CD`
  • Automation: Databricks CLI, SDKs (Python, Java and Go), REST APIs and Terraform provider`
  • Databricks Connect and VS Code / JetBrains extensions`
  • Drivers and integrations: JDBC/ODBC drivers, SQL connectors and dbt integration`
  • Partner Connect`

Security and administration

  • Identity: SSO, SCIM, identity federation (enabled by default for all new workspaces), service principals, OAuth and PAT policies databricks`
  • Networking: IP access lists, Private Link, customer-managed VPC/VNet, and serverless egress controls`
  • Compliance and encryption: customer-managed keys, compliance security profile, and enhanced security monitoring`
  • Cost management: budgets, budget policies, usage dashboards and tagging`

Industry solutions and editions

  • CustomerLake: Agentic customer data platform (CDP) built natively on the lakehouse flexera`
  • Lakewatch: Agentic security information and event management (SIEM), with the Panther acquisition pending flexera`
  • Free Edition: now includes Genie Code, serverless GPUs, Lakebase, Agent Bricks and LakeFlow Designer flexera`
  • Solution Accelerators`
